## 🌐 เวอร์ชันเว็บแอพ (PWA)

เว็บแอพตรวจจับความเคลื่อนไหวผ่านกล้องมือถือ — ไม่ต้องติดตั้งผ่าน App Store ใช้ได้ทั้ง Android และ iPhone

## ฟีเจอร์

- 🧍 **ตรวจจับเฉพาะคนและสัตว์** ด้วย AI (TensorFlow.js + COCO-SSD) — แสงเปลี่ยน/ต้นไม้ไหว/รถวิ่งผ่านจะไม่เตือน (ปิดกลับเป็นโหมดตรวจจับทุกอย่างได้)
- 👀 ตรวจจับความเคลื่อนไหวแบบเรียลไทม์ด้วยเทคนิค **frame differencing**
- 🟥 วาดกรอบสีแดงรอบบริเวณที่มีการเคลื่อนไหว
- 🔔 เสียงเตือนเมื่อพบความเคลื่อนไหว (เปิด/ปิดได้)
- 📸 ถ่ายภาพอัตโนมัติเมื่อพบความเคลื่อนไหว พร้อมแกลเลอรีในตัว
- 🎚️ ปรับความไว (sensitivity) ได้
- 🔄 สลับกล้องหน้า/หลัง
- 📱 ติดตั้งเป็นแอพบนหน้าจอโฮมได้ (PWA) และเปิดออฟไลน์ได้

## วิธีใช้งาน

กล้องต้องเปิดผ่าน **HTTPS** (หรือ `localhost`) เท่านั้น เนื่องจากเป็นข้อกำหนดความปลอดภัยของเบราว์เซอร์

### ทดสอบบนเครื่อง

```bash
# วิธีที่ 1: Python
python3 -m http.server 8000

# วิธีที่ 2: Node.js
npx serve .
```

แล้วเปิด `http://localhost:8000`

### ใช้บนมือถือจริง

Deploy ขึ้นบริการฟรีที่มี HTTPS ให้ เช่น **GitHub Pages**, Netlify หรือ Vercel แล้วเปิด URL จากมือถือ → กดอนุญาตใช้กล้อง → กด "เริ่มตรวจจับ"

เปิด GitHub Pages ได้ที่: Settings → Pages → Source = branch ที่ต้องการ

## หลักการทำงาน

1. ดึงภาพจากกล้องด้วย `getUserMedia`
2. ย่อภาพลงเหลือ 96×72 พิกเซล และแปลงเป็นขาวดำ (ประหยัด CPU บนมือถือ)
3. เปรียบเทียบความสว่างของแต่ละพิกเซลกับเฟรมก่อนหน้า
4. ถ้าสัดส่วนพิกเซลที่เปลี่ยนแปลงเกินเกณฑ์ (ตามค่า sensitivity) → ถือว่ามีความเคลื่อนไหว
5. โหมด AI (ค่าเริ่มต้น): ส่งภาพให้โมเดล COCO-SSD ตรวจว่ามี**คนหรือสัตว์** (คน แมว สุนัข นก ม้า วัว ฯลฯ) หรือไม่ — เตือน + ถ่ายภาพเฉพาะเมื่อเจอเท่านั้น พร้อมกรอบระบุชนิดและความมั่นใจ
   (AI ทำงานเฉพาะตอนมีความเคลื่อนไหว จึงประหยัดแบต — ถ้าโหลดโมเดลไม่ได้ เช่นออฟไลน์ จะถอยกลับเป็นโหมดตรวจจับทุกอย่างอัตโนมัติ)

## ข้อจำกัด

- iPhone (Safari) จะหยุดกล้องเมื่อพับหน้าจอหรือสลับแอพ — เป็นข้อจำกัดของ iOS
- ภาพที่บันทึกเก็บในหน้าเว็บเท่านั้น (สูงสุด 30 ภาพล่าสุด) ปิดหน้าแล้วหาย — กดค้างที่รูปเพื่อบันทึกลงเครื่องได้
- แสงที่เปลี่ยนกะทันหัน (เช่น เมฆบังแดด) อาจทำให้ตรวจจับผิดพลาด ลดความไวลงช่วยได้
